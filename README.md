# Planificador de comidas

Aplicación web (HTML + CSS + JavaScript) para organizar tus recetas en un plan semanal.

## Funcionalidades

- Alta y eliminación de recetas.
- Asignación de recetas para desayuno, almuerzo y cena por cada día de la semana.
- Lista de compras automática basada en ingredientes planificados.
- Persistencia local con `localStorage`.

## Ejecutar

Abre `index.html` directamente en tu navegador o usa un servidor estático:

```bash
python3 -m http.server 8000
```

Luego entra en `http://localhost:8000`.
